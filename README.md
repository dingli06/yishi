# 今日何食微信小程序

原生微信小程序前端，当前完成 T07 的契约 mock 切片。项目直接导入微信开发者工具即可预览。

## 当前可体验

- 首页条件：口味、餐食形态、优先食材与“只用已确认食材种类”。
- 单卡推荐：换一道、接受、收藏；同一轮按菜品去重。
- 详情：材料、步骤、来源时间口径、前置条件和来源链接。
- 独立记录收藏、接受和“做过”。
- 常用设置：长期排除食材、已确认常备食材。
- 加载、无候选、候选耗尽和可重试错误状态。
- 设置页可令下一次推荐模拟网络失败，用于检查条件保留与重试。

界面使用 `jinriheshi_starter` 中 4 条真实开发样板制作 mock。没有使用未审核来源图片，所有菜品图形都是中性文字占位。严格时间、人数和省事程度仍不可用；生产发布集合仍为 0。

## 本地检查

```bash
npm install
npm run typecheck
```

当前服务位于 `services/mock-api.ts`，模拟 T01 会话 revision 和按菜品去重语义。接入 T06 后以真实接口替换该模块，页面不应自行实现生产推荐规则。
